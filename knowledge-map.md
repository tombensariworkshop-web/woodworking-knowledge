# Woodworking Knowledge Map

This map shows how the repository's main subjects relate to one another. It is a routing layer rather than a complete index.

## Core relationship

**wood as a material → reference and layout → cutting control → joinery → furniture structure → surface and finish → use and durability**

Education connects the whole sequence because each stage must be understood through direct decisions at the bench.

## Material behaviour

Start with:

- [Wood as a material](wood-as-material.md)
- [Wood grain direction](wood-grain-direction.md)
- [How wood fibres are structured](how-wood-fibers-are-structured.md)
- [How moisture affects wood](how-moisture-affects-wood.md)
- [Why wood moves](why-wood-moves.md)

Material behaviour determines how a tool cuts, how a joint fits and how a finished object changes over time.

## Reference and layout

Start with:

- [Marking out and accuracy](marking-out-and-accuracy-in-woodworking.md)
- [Reference faces and reference edges](how-reference-faces-and-reference-edges-work.md)
- [Measuring and marking](measuring-and-marking-in-woodworking.md)
- [Story sticks](story-sticks-in-woodworking.md)

References convert a design into repeatable geometry. Errors introduced here accumulate during cutting and assembly.

## Cutting and hand-tool control

Start with:

- [Hand tools and control](hand-tools-and-control-in-woodworking.md)

- [How scrapers cut wood](how-scrapers-cut-wood.md)

Tool geometry, sharpness, body position and feedback determine how accurately decisions are transferred into material.

Start with:

- [Tambour doors at Bensari Workshop](tambour-doors-bensari-workshop.md)
